# Ayush Kumar Mahato | Portfolio

Portfolio site built with React, TypeScript, and Vite.

## Run locally

**Prerequisites:**  Node.js

1. Install dependencies:
   `npm install`
2. Start the development server:
   `npm run dev`

## Deploy to Netlify

Netlify uses `netlify.toml` to run `npm run build` and publish the generated `dist` directory. The configuration also pins a compatible Node.js version and routes client-side requests to the app entry point.
